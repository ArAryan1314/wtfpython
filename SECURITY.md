# Security Policy

This repository is a fork of [satwikkansal/wtfpython](https://github.com/satwikkansal/wtfpython).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/satwikkansal/wtfpython/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
